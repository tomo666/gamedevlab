# はじめてのJBASIC

## 目的

- JBASICの基本的な形（Start / Update）がわかる  
- どこに処理を書けばいいか迷わなくなる

## JBASICの基本の形

JBASICでは、プログラムの動きを作るために記述すべき「お作法」があります。まずは、プログラム本体を記述するために2つの関数を実装する必要があります。

- `Start`：アプリケーションの開始時に**一度だけ**呼ばれます。初期設定や準備を書く場所です。
- `Update`：一定時間間隔、または毎フレーム（例：1秒間に約60回）呼ばれます。アプリケーションの更新処理（ループ）を書く場所です。

なお、`Start` と `Update` 関数は省略可能です。ただし、Update 関数を記述する場合は、Start 関数の記述も必須です。Start が無い場合はコード全体が Start 関数の中身と同等として扱われます。

## 最小サンプル

```vb title="Sample.bas"
' アプリケーションが起動した時に一度だけ呼ばれる
FUNCTION Start()
  ' 起動時に実行したい内容をここに書く
END FUNCTION

' アプリケーションが起動している間は何度も呼ばれる
FUNCTION Update()
  ' 更新する度に実行したい処理をここに書く
END FUNCTION
```

今後はこの中に少しずつコードを追加してJBASICのイロハを学んでいきます。
